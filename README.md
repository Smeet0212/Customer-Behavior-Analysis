# Customer-Behavior-Analysis
BI-focused analysis of 3,900 customer transactions using Python, SQL, and Power BI. Built cleaned datasets, engineered features, performed SQL-based revenue and segmentation analysis, and developed interactive dashboards to track KPIs, customer segments, discounts, and subscription performance.

Data Analytics Project

Overview

This project demonstrates an end-to-end data analytics workflow, covering data extraction, exploration, cleaning, analysis, and visualization. The goal is to derive meaningful business insights from raw data and present them through interactive dashboards and professional reports to support data-driven decision-making.

Dataset

Loaded and analyzed a structured transactional dataset
Contains customer demographics, purchase details, and behavioral attributes
Used for identifying trends, patterns, and key performance indicators (KPIs)

Tools & Technologies

Python: Data loading, EDA, and data cleaning
SQL: Business analysis using PostgreSQL / MySQL / SQL Server
Power BI: Interactive dashboards and visualizations
Gamma: Professional presentation (PPT) creation
Excel / CSV: Source data format

Project Steps

1. Data Loading
  Imported dataset into Python using pandas

2. Exploratory Data Analysis (EDA)
  Analyzed distributions, trends, and summary statistics

3. Data Cleaning & Preparation
  Handled missing values, standardized columns, and engineered features

4. SQL Analysis

  Loaded cleaned data into a relational database
  Executed SQL queries to answer business questions

5.Dashboard Development
  Built an interactive Power BI dashboard to track KPIs and insights

6. Reporting & Presentation
   Created a business report and presentation using Gamma

Dashboard

The Power BI dashboard highlights:

* Key KPIs and summary metrics
* Customer segmentation and behavior trends
* Revenue and performance analysis
* Interactive filters for deeper insights


Results & Insights

* Identified key customer segments and high-value users
* Analyzed revenue drivers and purchasing patterns
* Evaluated discount and subscription impact
* Delivered actionable recommendations for business strategy


How to Run the Project

1. Clone the repository
2. Open the Python notebooks/scripts and install required libraries
3. Run data cleaning and analysis scripts
4. Load the processed data into your SQL database
5. Execute SQL queries for analysis
6. Open the Power BI file to explore the dashboard
